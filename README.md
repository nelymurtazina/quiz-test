# Quiz Test Application

## Описание задания

Необходимо реализовать приложение для прохождения теста на основе предоставленного макета Figma. Приложение должно отображать вопросы и варианты ответов, позволяя пользователю проходить тест и видеть результаты.

### Макет
- [Figma макет](https://www.figma.com/design/elaFiYhiBHfK0t0WpaW4vS/quiz-test--Copy-?node-id=0-1&p=f&t=1jTDXg5S5t0ZbDTa-0)

### Требования

1. **Git Workflow**:
   - Создать отдельную ветку для разработки (например, `feature/quiz-test`).
   - После завершения работы создать Merge Request (Pull Request) в основную ветку.

2. **Функционал приложения**:
   - Загрузка вопросов и ответов из файла `questions.json`.
   - Отображение вопросов и вариантов ответов в случайном порядке.
   - Кнопка "Next" активна только после выбора ответа.
   - Кнопка "Back" неактивна на первом вопросе.
   - После завершения теста кнопка "Start" перезапускает экзамен.

3. **Прогресс-бар**:
   - Зеленый цвет при прохождении теста и успешном завершении.
   - Красный цвет, если были даны неправильные ответы.

4. **Данные**:
   - Вопросы и ответы хранятся в формате JSON (`questions.json`).
   - Правильные ответы указаны в массиве внутри каждого вопроса.

### Критерии оценки
   - Соответствие макету Figma.
   - Корректная работа прогресс-бара и кнопок.
   - Правильная обработка ответов и отображение результата.
   - Чистый и читаемый код.
